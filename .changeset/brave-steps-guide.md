Recall guidance now describes lookup as a sequence. Search with several phrasings and date windows to locate evidence. Page observations for surrounding context. Read source messages to confirm details. When searches keep returning the same groups, the agent pages or reads sources instead of rephrasing again.

Recall search no longer returns full excerpts for groups already in context. It compacts groups that are in the active observations, and buffered groups whose messages haven't been activated yet. Groups condensed away by reflection still show their excerpts.
